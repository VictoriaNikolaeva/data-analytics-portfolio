ИНСТРУКЦИЯ ПО ЗАГРУЗКЕ ДАТАСЕТА И ЗАПУСКУ SQL

1. Скачайте датасет PaySim по ссылке:
https://www.kaggle.com/datasets/ealaxi/paysim1

Нажмите Download. Распакуйте скачанный архив и найдите файл:
PS_20174392719_1491204439457_log.csv

2. В папке проекта создайте каталог data/raw и поместите в него этот CSV-файл.

Проверьте, что структура проекта выглядит так:

project-folder/
    project.sql
    data/
        raw/
            PS_20174392719_1491204439457_log.csv
        sample/
            paysim_sample.csv

3. Откройте терминал из корневой папки проекта — там, где находится project.sql.

Если база fintech ещё не создана, выполните:
createdb -U postgres fintech

4. Запустите SQL-сценарий:
psql -U postgres -d fintech -v ON_ERROR_STOP=1 -f project.sql

При необходимости замените postgres на имя своего пользователя PostgreSQL. После завершения сценария основные таблицы будут доступны в схеме marts.

5. Проверьте количество загруженных транзакций:
psql -U postgres -d fintech -c "SELECT COUNT(*) FROM marts.fact_transaction;"

Для полного датасета ожидается 6 362 620 строк.

Примечание: полный CSV не включён в архив проекта. Его нужно скачать отдельно по ссылке из пункта 1.
