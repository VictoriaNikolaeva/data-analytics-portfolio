# Предсказание цены автомобиля по объявлениям

Учебный проект по анализу данных. Разбираю, от чего зависит цена машины в объявлениях, и строю модель, которая её предсказывает.

## Данные

Датасет [Car Sales Information](https://www.kaggle.com/datasets/ekibee/car-sales-information) с Kaggle – 1 294 757 объявлений с сайта Drom, 18 признаков: марка, модель, год выпуска, пробег, объём и мощность двигателя, тип кузова, коробка передач, привод, тип топлива, цена и другие.

После удаления повторов, заполнения пропусков и отсечения выбросов по пробегу и мощности для анализа осталось 897 885 объявлений.

## Что я делала

- **Очистка.** Убрала 344 300 повторных записей (сайт собирали в несколько проходов, оставила последнюю версию каждого объявления), разобрала пропуски по каждому признаку.
- **Выбросы.** Два метода – 3 стандартных отклонения и 1.5 IQR.
- **Новые признаки.** Например, возраст автомобиля из года выпуска.
- **Разведочный анализ.** Распределения, скрипичные графики, описательные статистики по цене и предикторам.
- **Кодирование категорий.** One-Hot, LabelEncoder, OrdinalEncoder.
- **Корреляция.** Парная, корреляционная матрица, топ-5 признаков.
- **Модель.** Линейная регрессия для логарифма цены: уравнение, интерпретация коэффициентов, метрики качества.
- **Проверка 8 статистических гипотез.** Тест Шапиро-Уилка, одно- и двухвыборочный t-тест, парный t-тест, z-тест, z-тест для долей, критерий Манна-Уитни, хи-квадрат.

## Результаты

- Сильнее всего цена связана с **возрастом**: корреляция с логарифмом цены −0,73. Новые машины заметно дороже старых.
- Цена растёт с мощностью и снижается с пробегом. Из категорий важны коробка (механика дешевле) и тип топлива (дизель дороже бензина).
- Линейная регрессия объясняет **81% вариации** логарифма цены на тестовой выборке (R² ≈ 0,81), средняя ошибка прогноза около 367 тыс. руб.
- Увеличение возраста на 9,2 года снижает цену примерно на 40% при прочих равных.

## Ограничения

В работе использованы цены объявлений за 2023 год, а не цены реальных сделок. Часть значений года выпуска и пробега заполнена медианами. Для более точного прогноза нужны данные о состоянии и комплектации, которых в датасете нет.

## Стек

Python, pandas, NumPy, scikit-learn, SciPy, statsmodels, Jupyter Notebook.

## Как смотреть

Открыть `car_price_analysis.ipynb` – GitHub показывает ноутбук прямо в браузере, с кодом, графиками и выводами.

## Как запустить локально

1. Скачайте датасет по ссылке выше и распакуйте `all_regions.csv` в папку `car-price-prediction` рядом с ноутбуком.
2. Установите зависимости: `python -m pip install -r requirements.txt`.
3. Запустите `jupyter notebook` из папки проекта, откройте `car_price_analysis.ipynb` и выполните ячейки по порядку.

Полный CSV не включён в репозиторий. В ноутбуке сохранены результаты предыдущего выполнения, поэтому код, графики и выводы можно просматривать без локального запуска.
